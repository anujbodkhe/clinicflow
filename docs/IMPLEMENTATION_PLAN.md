## Dependency order

`P0-1` and `P0-2` are prerequisites for safe feature decisions. Then complete `P1-1`, `P1-3`, and `P1-4`; queue visibility (`P1-2`) follows registration. Queue calculations and moderation (`P2-*`) depend on a canonical queue/state model. Clinical access (`P3-1`) precedes consultation/prescription and private PDF work (`P3-2`, `P3-3`). Analytics and optional AI depend on persisted, authorized data. Release hardening is last.
